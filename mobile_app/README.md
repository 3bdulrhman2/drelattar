# تطبيق «عيادتي | My Clinic» - عيادة د. محمد السيد العطار

تطبيق أندرويد متكامل مبني بواسطة Flutter لإدارة عيادة الدكتور محمد السيد العطار وحجوزاتها وتنظيم مواعيدها وربطها المباشر واللحظي مع الموقع الإلكتروني الرسمي [https://elattar.site](https://elattar.site).

---

## 🌟 مميزات التطبيق

### 1. نظام الدخول وصلاحيات الأدوار (Role-Based Access)
- **الطبيب صاحب العيادة (Admin):**
  - الوصول الكامل لجميع أقسام التطبيق: الرئيسية، الحجوزات، الإجازات، إدارة الموقع، والمزيد.
  - إدارة وإضافة حسابات السكرتارية وتحديد بيانات الدخول وتفعيلها أو إيقافها فورياً.
  - إدارة التقييمات ومواعيد العمل والتحويل المباشر إلى لوحة تحكم الموقع CMS.
- **مشرف الحجوزات / السكرتارية (Secretary):**
  - واجهة مبسطة وسريعة مخصصة لمهام السكرتارية اليومية (3 تبويبات فقط: الرئيسية، الحجوزات، تنظيم المواعيد).
  - حجب كامل لأي إعدادات إدارية، تعديلات بالموقع، أو إدارة المستخدمين.
  - إمكانية تأكيد وإلغاء وإتمام الحجوزات، الاتصال بالمريض هاتفياً أو فتح واتساب بنقرة واحدة.

### 2. إدارة الحجوزات اللحظية الموحدة (Real-Time Booking)
- مزامنة مباشرة عبر قاعدة بيانات Supabase المشتركة بين الموقع والتطبيق.
- أي حجز يتم من الموقع يظهر في التطبيق لحظياً، وأي تحديث لحالة الحجز ينعكس فورياً على الموقع.
- إمكانية البحث باسم المريض، رقم الهاتف، أو كود الحجز.
- تصفية سريعة: اليوم، غداً، القادمة، السابقة، المعلقة، المؤكدة، المكتملة، الملغية.

### 3. نظام الإجازات والتعطيل والإعلانات الفورية
- إمكانية إغلاق حجوزات اليوم فوراً بالموقع («إغلاق الحجوزات اليوم»).
- إمكانية حجب يوم محدد مستقبلاً من الحجز.
- جدولة إجازات رسمية وفترات عطلات (عيد، سفر، دورات).
- نشر تنبيهات وشريط إشعار عاجل أعلى الموقع يظهر فوراً لكافة الزوار.

### 4. الإشعارات اللحظية (Push Notifications)
- دعم Firebase Cloud Messaging (FCM) والإشعارات المحلية لنظام أندرويد.
- استقبال تنبيه فوري فور قيام أي مريض بحجز موعد جديد.

## 🎨 الهوية البصرية وشعار التطبيق
- استخدام الشعار الرسمي الأصلي للعيادة بدقة كاملة ونسب متناسقة (`BoxFit.contain`).
- أيقونة أندرويد مخصصة بخلفية زرقاء طبية داكنة موحدة (`#123E91`) وآمنة للمسافات مع دعم Adaptive Icons.
- شاشة افتتاحية (Splash Screen) رسمية متحركة وسلسة بشعار العيادة.
- تصميم عربي موجه بالكامل (RTL) بألوان الهوية: Royal Navy `#123E91`, Medical Blue `#1A56DB`, Lime Accent `#84CC16`.

## 🛠️ تشغيل التطبيق وبناء الـ APK
```bash
# تثبيت الحزم
flutter pub get

# فحص الكود والتأكد من خلوه من الأخطاء
flutter analyze

# بناء ملف APK للتشغيل
flutter build apk --debug
# أو بناء ملف Release النهائي
flutter build apk --release
```
ملف الـ APK الناتج يتواجد في:
`mobile_app/build/app/outputs/flutter-apk/app-debug.apk` أو `app-release.apk`.
